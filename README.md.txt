# Supply Chain Analytics Dashboard | تحليل سلسلة الإمداد

## 📌 نظرة عامة على المشروع
يهدف المشروع إلى تحليل أداء سلسلة الإمداد باستخدام Power BI، من خلال دراسة المبيعات والطلبات والعملاء وفئات المنتجات والدول وطرق الشحن، مع التركيز على مخاطر تأخر التسليم واتجاهات المبيعات عبر الزمن.

## 🛠️ الأدوات المستخدمة
- **Power BI:** تصميم لوحة معلومات تفاعلية.
- **Power Query:** تنظيف البيانات وتجهيزها.
- **DAX:** إنشاء المقاييس ومؤشرات الأداء الرئيسية.

## 🧹 تنظيف البيانات
تم استخدام Power Query لتجهيز البيانات للتحليل، وشملت الخطوات:
- حذف الأعمدة غير الضرورية، مثل Product Image وOrder Zipcode.
- مراجعة أنواع البيانات وتجهيزها للتحليل.
- الاحتفاظ بالأعمدة المهمة لتحليل حالات الطلبات وطرق الشحن والدول.
- تجهيز البيانات لإنشاء المقاييس والرسوم البيانية التفاعلية.

## 📊 مؤشرات الأداء الرئيسية (KPIs)

- إجمالي الطلبات: **66 ألف تقريبًا**.
- إجمالي العملاء: **21 ألف تقريبًا**.

- الطلبات المصنفة ضمن مخاطر تأخر التسليم: **36 ألف تقريبًا**.
